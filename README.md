# euler-assets

Token / network / platform icons, ABIs, and email-template CDK. Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/euler-assets-archive`.

Dropped before publish: generated `email-templates/cdk.context.json`, and the `premioseficacia/` client tree.

No contract deployments recorded in this repo (ABIs only).

## What was built

Euler Assets was a centralized registry of blockchain token metadata, icons, and smart contract ABIs used across the Euler DeFi platform. Structured data for tokens on BSC, Ethereum, Polygon, HECO, OKEx, EOS, Fantom, and Tron, plus DEX/platform icons, wallet connector icons, network icons, and BSC ABIs. `email-templates` is a small CDK app for S3-hosted email template sites.

## Qué se construyó

Registro de metadatos e iconos de tokens y ABIs. Se eliminó el árbol de cliente `premioseficacia` y el contexto CDK.
